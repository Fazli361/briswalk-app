# Borang Pendaftaran Program Briskwalk

Aplikasi pendaftaran rasmi Program Briskwalk anjuran Panel Penasihat Klinik Kesihatan Changkat Jering dengan sokongan integrasi pangkalan data Google Sheets.

## Ciri-Ciri Utama:
- **Pendaftaran Mudah & Pantas:** Nama penuh (automatik huruf besar), No. Kad Pengenalan 12-digit (1 KP = 1 Pendaftaran), dan No. Telefon.
- **Integrasi Google Sheets Terus:** Data dihantar terus ke Google Sheets sebaik sahaja pengguna menekan butang SUBMIT.
- **Penyegerakan Automatik (Live Sync):** Paparan kuota dikemas kini secara automatik terus dari Google Sheet apabila pengguna membuka borang.
- **Panel Pentadbir Selamat:** Dilindungi dengan kata laluan untuk melihat senarai peserta, menyegerak rekod dari Google Sheet, memuat turun CSV/Excel, dan mengurus tetapan pangkalan data.
